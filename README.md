# 📈 모의 주식 투자 — 설정 가이드

준비물: 구글 계정, GitHub 계정(무료), 관리자용 노트북 1대. 전부 무료야. 처음 하면 30분 정도 걸려.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | **참가자 화면** (QR로 들어오는 곳) |
| `admin.html` | **운영자 화면** (게임 엔진 + 프로젝터 모드) |
| `config.js` | ⚠️ **Firebase 설정값 + 관리자 이메일을 넣는 곳** |
| `database.rules.json` | Firebase 보안 규칙 (참가자가 돈을 직접 못 바꾸게 막음) |
| 나머지 `.js` `.css` | 게임 로직이랑 디자인. 건드릴 필요 없음 |

## 1단계. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 접속 → **프로젝트 추가(만들기)**
2. 이름은 아무거나 (예: `mock-stock`). Google 애널리틱스는 **꺼도 됨**.

## 2단계. Realtime Database 만들기

1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르 (asia-southeast1)** 추천 (한국이랑 가까움)
3. **잠금 모드로 시작** 선택 → 사용 설정
4. 위쪽 **규칙** 탭 클릭
5. `database.rules.json` 파일을 메모장으로 열어서, `admin@example.com`을 **전부** 내 관리자 이메일로 바꿔줘 (메모장에서 `Ctrl+H` → 모두 바꾸기). 이메일은 **소문자**로 써.
6. 바꾼 내용을 규칙 편집기에 통째로 붙여넣기 → **게시**

## 3단계. 로그인 방식 켜기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭에서 두 개를 사용 설정:
   - **익명** → 사용 설정 → 저장 (참가자는 로그인 없이 들어옴)
   - **이메일/비밀번호** → 사용 설정 → 저장
3. **사용자** 탭 → **사용자 추가** → 관리자 이메일(2단계에서 쓴 것과 똑같이)과 비밀번호 입력

## 4단계. config.js 채우기

1. 왼쪽 위 ⚙️ **프로젝트 설정** → 아래쪽 **내 앱** → 웹 아이콘 `</>` 클릭
2. 앱 닉네임 아무거나 → **앱 등록** (Firebase 호스팅 체크는 안 해도 됨)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사
4. `config.js`를 메모장으로 열어서 `firebaseConfig = { ... }` 부분을 복사한 걸로 교체
   - ⚠️ `databaseURL` 줄이 꼭 있어야 해. 없으면 Realtime Database 화면 맨 위에 있는 주소(`https://...firebasedatabase.app`)를 직접 넣어줘.
5. 같은 파일의 `ADMIN_EMAIL`을 관리자 이메일로 바꾸기
6. (선택) `GAME_TITLE`에 게임 이름 쓰기

## 5단계. 인터넷에 올리기 (GitHub Pages)

1. https://github.com 가입 → 오른쪽 위 **+ → New repository**
2. 이름 아무거나 (예: `stock`), **Public** 선택 → **Create repository**
3. **uploading an existing file** 링크 클릭 → 폴더 안의 **파일 전부**를 드래그 → **Commit changes**
4. 저장소 **Settings → Pages** → Branch를 **main** / **/(root)**로 고르고 **Save**
5. 1~2분 기다리면 주소가 생겨: `https://내아이디.github.io/stock/`
   - 참가자 주소: `https://내아이디.github.io/stock/`
   - 운영자 주소: `https://내아이디.github.io/stock/admin.html`
6. Firebase **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 추가

> 파일을 고쳤으면 GitHub에 다시 올리면 돼. 반영은 1~2분 뒤에 되고, 안 바뀌면 폰에서 새로고침해줘.

## 리허설 (꼭 해줘!)

1. 노트북에서 운영자 주소 열기 → 로그인
2. **📝 문제 → ✏️ 문제 입력/수정**에 문제 넣고 저장
3. 친구 3~4명이 폰으로 참가자 주소 접속 → 닉네임 + 팀 번호 입력 (최소 2팀)
4. **▶ 게임 시작** → **🏟 토너먼트 시작** → **다음 문제 공개** → 사고팔기, 문제 풀기(일부러 3번 틀려보기 포함), 아레나 결투, **이번 라운드 지금 끝내기**까지 다 해보기
5. 끝나면 **♻ 전체 초기화** (참가자랑 기록만 지워지고 설정이랑 문제는 남아)

**학교 와이파이에서 꼭 한 번 해봐.** 학교망이 Firebase를 막는 경우가 있어. 그러면 폰은 LTE로 들어오라고 안내하면 돼.

## 당일 진행 순서

1. 노트북 **절전 모드 끄기**, 충전기 연결
2. 운영자 화면 열기 → 프로젝터 연결 → **📺 프로젝터 모드**
   - 시작 전에는 **QR코드 + 팀별 인원**이 크게 떠
3. 다 들어왔으면 프로젝터 모드에서 `Esc` → **▶ 게임 시작** → **🏟 토너먼트 시작** → 다시 프로젝터 모드
   - 게임 중에는 시세판, 토너먼트 현재 대진(실시간 수익률), 팀 수익률 랭킹, 속보, 새 문제 공개 알림이 큰 화면에 나와
4. 원할 때 속보 터뜨리기: `Esc` → 📰 속보 발동 → 다시 프로젝터 모드
5. 시간이 다 되면 자동 종료 → 프로젝터에 **토너먼트 우승 팀** + 수익률 🥇🥈🥉

### ⚠️ 중요
- **운영자 창이 게임 서버야.** 게임 중에 창을 닫거나 다른 탭으로 오래 가 있지 마.
- 운영자 창은 **한 개만** 열어. 두 개를 열면 두 번째 창이 막아줘.
- 실수로 닫히거나 새로고침해도 다시 열고 로그인하면 **이어서 진행돼** (최대 10초 전 상태로).
- 운영자 창이 꺼져 있는 동안 들어온 주문은 다시 켜졌을 때 그때 가격으로 처리돼.

## 게임 규칙 (참가자 안내용)

- 입장할 때 **닉네임 + 팀 번호**를 써. **같은 팀 번호끼리 현금, 주식, 아이템을 같이 써.** 팀원 누가 사고팔아도 팀 계좌에서 나가.
- 팀원 1명당 **100만 원**씩 팀 자금이 쌓여 (9명 팀이면 900만 원).
- 순위는 **수익률**로 매겨. 인원이 달라도 공평하게 겨룰 수 있어.
- 가상 회사 **8개**를 사고팔아. 매수/매도할 때 **수수료 0.5%**.
- **많이 사면 가격이 오르고, 많이 팔면 떨어져.** 한 번에 크게 사면 사는 동안 가격이 올라서 평균 체결가가 비싸져.
- 현금이 모자라도 **1명당 100만 원까지** 빚으로 살 수 있어. 대신 팀 총자산이 **1명당 -50만 원 이하**가 되면 **팀 전체 파산 → 아웃**.
- **속보**: 몇 분마다 자동으로 나오고, 운영자가 직접 터뜨리기도 해. 호재면 오르고 악재면 떨어져.
- **📝 문제**: 운영자가 문제를 하나씩 공개해. 공개된 문제는 **제한시간 없이** 게임 끝날 때까지 풀 수 있어. 정보 문제처럼 **범위(부분 문제)가 여러 개**면 범위마다 정답이 따로 있고, **범위 하나 풀 때마다 팀 아이템 1개**야. 범위마다 **팀 전체가 3번**까지 답을 낼 수 있고 (팀원끼리 기회 공유), 3번 다 틀리면 그 범위는 끝. 다른 팀이 먼저 풀어도 우리 팀은 계속 풀 수 있어.
- **팀 아이템** (팀원 누구나 사용 가능)
  - 🛡️ 손실 방지: 다음에 손해 보면서 팔 때 1번은 본전으로 팔림
  - ✖️2 수익 2배: 다음에 이익 보면서 팔 때 1번은 수익이 2배
  - 💸 수수료 면제: 3분 동안 수수료 0원
  - 📰 속보 미리보기: 다음 정기 속보 내용과 시간을 팀 전원에게 미리 알려줌
  - 🔄 수익률 교환: 무작위 다른 팀과 **수익률**을 맞바꿈. 상대 포트폴리오를 우리 팀 규모에 맞춰서 받는 거야. 도박!
- **⚔️ 아레나 결투 (개인)**: 아레나에 들어가서 기다리다가 **다른 팀** 사람이 들어오면 결투 시작 (같은 팀끼리는 안 붙어). 각자 1~10 숫자 카드 5장을 받고, 5라운드 동안 1장씩 내서 큰 숫자가 그 라운드 승리. 이긴 사람은 **진 사람 몫(팀 재산 ÷ 팀원 수)의 절반**이나 **상대 팀 아이템 1개**를 우리 팀으로 가져와. 동점이면 무승부.
- **🏟 토너먼트**: 운영자가 시작하면 **랜덤 대진**이 짜여. 라운드마다 두 팀씩 붙어서, **그 라운드 동안 수익률이 더 오른 팀**이 다음 라운드로 올라가. 팀 수가 홀수면 한 팀은 랜덤으로 부전승. 진 팀은 토너먼트에서만 빠지고, 주식이랑 랭킹은 계속할 수 있어.

## 참가자 화면 구성

아래쪽 탭을 누르거나 **옆으로 넘겨서** 페이지를 바꿔 (스프레드시트 시트 탭처럼).

| 페이지 | 내용 |
|---|---|
| 📈 주식 | 속보, 종목 8개 시세. 누르면 차트와 매수/매도 |
| 👥 우리 팀 | 팀 총자산·수익률, 팀 아이템 사용, 보유 주식, 팀원, 팀 활동 기록 |
| ⚔️ 결투 | 아레나 입장, 카드 결투, 진행 중인 결투 |
| 📝 문제 | 공개된 문제와 범위별 답 입력, 남은 기회, 다른 팀 해결 수 |
| 🏆 순위 | 우리 팀 현재 토너먼트 매치, 대진표, 팀 순위 |

새 문제가 공개되면 📝 탭에, 결투가 잡히면 ⚔️ 탭에 빨간 점이 떠.

## 토너먼트 운영 팁

- 다들 팀에 들어온 다음 **▶ 게임 시작 → 🏟 토너먼트 시작**을 눌러. 토너먼트 시작 뒤에 새로 생긴 팀은 대진에 못 들어가. 이미 있는 팀에 늦게 들어오는 건 괜찮아. 늦게 온 사람의 돈은 그 라운드 수익률 계산에서 빠지게 해놨어.
- 라운드 길이는 기본이 **자동**이야. 남은 게임 시간을 필요한 라운드 수로 나눠. 예를 들어 8팀이면 3라운드니까, 남은 시간이 54분이면 라운드당 약 18분이야.
- 라운드 길이를 직접 정하고 싶으면 설정에서 **토너먼트 라운드 길이**를 분 단위로 넣어.
- 운영자 화면의 **이번 라운드 지금 끝내기**를 누르면 그 순간 수익률로 승패가 정해지고, 다음 라운드가 바로 시작돼.
- 수익률까지 똑같으면 총자산이 많은 팀이 이기고, 그것까지 같으면 랜덤이야.

## 운영자 화면에서 바꿀 수 있는 것 (⚙️ 설정)

| 설정 | 기본값 | 설명 |
|---|---|---|
| 시작 자금 | 1,000,000 | 팀원 1명당. 새로 들어오는 사람부터 적용 |
| 팀 번호 최대 | 20 | 팀 번호를 1~20으로 제한해서 오타 방지 |
| 게임 시간 | 60분 | 게임 중에 바꾸면 남은 시간이 늘거나 줄어 |
| 수수료 | 0.5% | |
| 빚 한도 | 1,000,000 | 1명당. 팀 현금이 (이 값 × 인원)까지 마이너스 가능 |
| 파산 기준 | -500,000 | 1명당. 팀 총자산이 (이 값 × 인원) 이하면 아웃 |
| 정기 속보 간격 | 4분 | 실제로는 3~5분 사이 무작위. 0이면 꺼짐 |
| 문제 범위당 시도 횟수 | 3 | 범위마다 팀 전체가 답을 낼 수 있는 횟수 |
| 거래량 둔감도 | 1 | 2로 올리면 대량 매매에 가격이 덜 흔들려 |
| 결투 라운드 시간 | 20초 | 안 내면 자동으로 아무 카드나 나감 |
| 결투 보상 비율 | 50% | 진 사람 몫의 몇 %를 가져갈지 |
| 토너먼트 라운드 길이 | 0 (자동) | 분 단위로 직접 정할 수도 있어 |

팀 목록에서 팀에 **🎁 아이템 주기**, 파산한 팀 **부활**을 할 수 있어. 팀원 이름을 누르면 그 사람을 **추방**해 (팀 돈은 그대로 남아).

## 문제 입력 형식

운영자 화면 **📝 문제 → ✏️ 문제 입력/수정**에 붙여넣고 **저장**.

```
T: 1부터 N까지의 합
Q: 1부터 N까지 모든 정수의 합을 구하시오.

입력: 정수 N
출력: 합
P: N = 100
A: 5050
P: N = 1,000,000,000
A: 500000000500000000

T: 화학
Q: 물의 화학식은?
O: CO2 | H2O | NaCl
A: 2

Q: 2^10은?
A: 1024
```

| 줄 | 뜻 |
|---|---|
| `T:` | 제목 (없어도 됨, 없으면 본문 앞부분이 제목) |
| `Q:` | 본문. 다음 `P:`/`O:`/`A:` 줄이 나올 때까지 **빈 줄 포함 전부 본문**이야 (입력·출력 형식 써도 됨) |
| `P:` | 범위 이름 (예: `1 ≤ N ≤ 100`). 범위마다 정답이 따로 있고, 하나 풀 때마다 아이템 1개 |
| `A:` | 바로 위 범위의 정답. `A:` 줄을 여러 개 쓰면 다 정답으로 인정 |
| `O:` | 객관식 보기 (`|`로 구분). 이때 `A:`에는 정답 **번호** |

- `P:` 없이 `A:`만 쓰면 범위 1개짜리 문제야 (수학·과학 문제는 이렇게).
- 다음 `T:`나 `Q:`가 나오면 새 문제가 시작돼.
- 숫자는 `1,024` = `1024` = `1024.0`으로 처리해. **아주 큰 정수(10^18 넘는 수)도 한 자리까지 정확히 비교**해.
- 띄어쓰기와 대소문자는 무시해. 단위가 붙을 수 있는 답(예: `30만`, `300000`)은 `A:` 줄을 여러 개 써서 다 인정해줘.
- ⚠️ 이미 공개한 문제의 제목이나 본문을 고치면 새 문제로 취급돼서 그 문제의 팀 진행 기록이 없어져. 정답(`A:`)만 고치는 건 괜찮아.

## 무료 한도

Firebase 무료 요금제(Spark)는 **동시 접속 100명**, **월 10GB 다운로드**까지 무료야.
- 70명 + 운영자 노트북이면 동시 접속 100명 안에 들어가. (팀 단위로 해도 접속은 사람마다 따로 세) 한 사람이 폰이랑 태블릿을 동시에 켜면 2명으로 세니까, 참가자가 90명을 넘으면 주의해.
- 테스트 결과 70명이 1시간 하면 다운로드가 **약 1GB** 정도야. 리허설까지 해도 충분해.
- 무료 요금제는 한도를 넘어도 **돈이 청구되지 않고** 그냥 멈춰. 카드 등록도 안 해도 돼.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "config.js에 Firebase 설정값을 아직 안 넣었어" | 4단계 다시 확인 |
| 운영자 로그인 실패 | 3단계에서 만든 이메일/비번 확인. 이메일/비밀번호 로그인을 켰는지 확인 |
| "관리자 계정이 아니야" | `config.js`의 `ADMIN_EMAIL`이 로그인한 이메일과 똑같은지 확인 |
| 운영자 화면에 "데이터 저장 실패: PERMISSION_DENIED" | 보안 규칙의 이메일이 관리자 이메일과 똑같은지 (소문자로) 확인하고 다시 게시 |
| 참가자가 "입장하기" 눌러도 반응 없음 | 운영자 화면이 켜져 있는지 확인 (운영자 창이 입장을 처리함). 익명 로그인을 켰는지 확인 |
| 참가자 화면에 "운영자 서버가 응답이 없어" | 운영자 노트북 인터넷이나 창 상태 확인 |
| 폰에서 접속이 안 됨 | 학교 와이파이 문제일 수 있음 → LTE로 접속 |

## 속임수에 대해

참가자는 **주문 요청만** 보낼 수 있어. 돈, 주식, 아이템, 가격, 대진은 운영자 창만 바꿀 수 있게 보안 규칙으로 막아놨어. 결투 상대의 카드, 문제 정답, 다른 팀의 계좌도 참가자 쪽에서는 볼 수 없어.

⚠️ 팀 번호는 본인이 입력하는 거라서, 다른 팀 번호를 써서 들어가는 건 막을 수 없어. 시작 전에 프로젝터의 팀별 인원을 보고 확인해줘. 잘못 들어간 사람은 운영자 화면에서 추방하고 다시 들어오게 하면 돼.
